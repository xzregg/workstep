# 通知钩子实施记录

按 HTML 原型实现流程级多目标通知：钉钉、企业微信、通用 JSON，事件订阅、消息预览、真实测试、投递记录与重试。触发钩子与通知钩子在同一入口中明确区分，分别由自管理模块持有状态。

设备持有配置与持久化投递队列，直接访问接收地址；网关只开放相应的项目编辑管理路由，不保存通知副本或代发。任务事件使用真实执行轮次生命周期，步骤事件复用现有状态及交互事件。重试最多 3 次，已落库队列跨重启恢复，不承诺严格事务一致或恰好一次。

实现、接口与边界详见 [通知钩子技术说明](../docs/notification-hooks.md)。合并交付节点再集中同步用户手册及固定演示项目截图。
