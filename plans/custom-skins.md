# 动态皮肤实施计划

基于 dev 的独立 worktree：feature/custom-skins。默认皮肤继承当前界面；用户包不执行代码。

1. 先测试：包格式、共享契约、资源限制、注册/替换/导出、API 鉴权及慢 I/O canary。
2. 实现共享契约、皮肤包服务、API 与 CLI，接入普通聊天工作区。
3. 实现前端编译器、偏好保存、预览/取消/恢复、独立设置模块。
4. 接入全站样式部位、公共选择器、组件状态、受支持布局和独立主题。
5. 测试：组件事件、动态切换、全量前端回归、构建、后台 API、实际窄屏渲染。

首版布局：导航左右/宽度、内容宽度、密度、步骤左右/比例/拖柄宽度、输入工具栏位置、引擎列表/卡片。
工作台皮肤各客户端独立选择，同一 daemon 共用包；不纳入官网、网关账号页和系统原生窗口。
包位于 CONFIG_DIR/runtime/skins；规范位于 daemon/data/skins/contract.json，前后端共享。
用户手册在合并交付节点同步，本功能分支不执行合并、推送、发布。

## 实施结果

上述五步已完成。入口为设置 → 外观与皮肤；已提供普通项目聊天制作、注册校验、ZIP 导入导出、动态预览/应用/取消和固定恢复栏。

规范已登记 1664 个部位。公共选择器保留真实 change 事件；布局逻辑与皮肤外观分离，发送/停止、审批、引擎交接、权限和分享规则仍由业务模块持有。

验证：后台相关回归 194 项通过，前端全量 1332 项通过。类型检查、生产构建、lint、规范同步和 diff 检查通过。浏览器使用实际生产构建与隔离模拟接口，在 320、390、1023、1024、1280px 验证无溢出、触控尺寸、选项禁用、嵌套 Esc、跨断点窗口保持、预览取消和恢复默认；没有启动项目服务或调用真实 LLM。

首版限制：不开放任意 React 模板、脚本、远程资源或系统原生窗口；布局按上述已实现字段配置。包的格式校验与视觉验收分开，手册随后续合并交付集中同步。

## 双栏聊天与微调

按确认的原型接入 SkinStudio：左侧嵌入现有项目对话，右侧手动微调名称、配色、引擎呈现和布局。微调与 CLI 生成共用目录，发送前保存、回合结束重新读取；增加版本冲突拒绝、运行态禁用和未保存关闭保护。独立沙箱预览按 PC／手机尺寸编译草稿，不改变当前皮肤。

前端全量 1400 项和后台皮肤相关 22 项通过；生产构建、lint、规范同步及四档宽度实际浏览器验收通过。HTML 原型保存在 plans/prototypes/skin-center.html，标记为模拟交互，不调用真实模型。

## 固定 Runtime 项目

技能、引擎和皮肤制作统一复用固定 Runtime 项目，默认根目录 ~/.workstep/runtime/workspace/。只初始化一次项目，之后创建普通会话；系统不分配类型或草稿 ID 目录。包文件由对话在根目录自行创建，皮肤右栏支持指定并读取实际包目录。已安装技能库和旧制作成果保持原样，Runtime 根目录不参与技能库扫描。

相关后台 55 项通过，前端全量回归 1401 项及补充的首次无皮肤包聊天测试通过；统一项目并发初始化、重启身份、无自动草稿目录、宿主权限和慢 SQL 响应均已覆盖。目录及入口见 docs/customization-workspace.md。
