# 新手引导

WorkStep 为全新安装用户提供可跳过、可收起并可从侧边栏重新打开的激活清单。用户名仍为首次使用的必填信息；保存后用户可选择进入快速设置或直接使用产品。

快速设置按真实资源状态推进：

1. 保存一个已启用、具备有效地址与认证信息的供应商。
2. 显式选择与该供应商协议兼容、已安装并已配置的默认执行引擎。
3. 初始化一个本地项目。
4. 创建使用所选引擎的“需求分析 → 执行任务”双阶段流程。
5. 使用该流程创建首个任务。

引导状态保存在 `workstep:onboarding:v1`，只保存状态与资源标识；每次重新打开仍通过现有 API 核验供应商、引擎、项目、流程和任务是否存在。资源被删除后，引导回退到对应步骤。

首个任务创建成功即视为完成，不自动运行，不产生隐式模型调用。示例流程画布只显示一次上下文提示，用于解释阶段产物如何沿连线传递。

验收要求：

- 已有用户名的升级用户不会被自动打扰。
- 跳过、收起、刷新恢复和手动重新打开均可用。
- 引导复用现有设置、项目、流程和任务界面，不复制业务表单。
- 四套语言词典键一致且非空。
- 前端测试、静态检查与生产构建通过。
