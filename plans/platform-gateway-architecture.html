WorkStep · Platform Gateway

平台网关模式架构

Gateway 负责认证、设备、项目授权和供应商策略。本机客户端认证后直接访问 loopback daemon；从 Gateway 门户进入 PC 或远程项目时，才建立按需数据 WSS 代理 HTTP / WebSocket。

网关同时管理访问与供应商策略

直接打开客户端：Gateway 认证后走本机 loopback。Gateway 门户可按整机授权打开 PC，也可按用户/组的 read/edit 授权直接打开远程项目。

PC 主动连接

  • 软件配置网关地址并完成设备注册。
  • PC 主动建立控制 WSS 长连接，承载心跳、策略、命令、用量和审计回传。
  • 仅门户远程访问时建立数据 WSS，转发 HTTP、业务 WebSocket 和文件流。

供应商下发，本机直接使用

Gateway 按设备公钥下发签名配置包，PC 写入现有供应商配置并复用当前加载接口。模型请求不经过 Gateway，受管配置在本机只读。
