日期：2026-10-03。范围按用户最新要求限定为自主注册；企业微信／钉钉真实跳转暂不验证。

## 已验证的行为

- 开放注册：账号创建及会话签发，注册后返回原目标，普通用户无管理权限；密码以 Argon2id 哈希保存，Cookie 使用 Secure、HttpOnly、SameSite。
- 审核注册：不签发会话，审批前拒绝登录；管理员批准后可登录，等待页保留原目标。
- 关闭注册：无页面注册入口，直接调用 API 拒绝；密码计算期间策略改变时，提交事务按最新策略执行。
- 校验及恢复：用户名、显示名称、密码长度和密码确认；重复用户名、网络失败、限流后可修改或重试。
- 并发：提交期间锁定表单，重复提交不叠加；同名并发注册只提交一个账号和一个会话。
- 隔离：企业身份源的可选请求失败不阻断自主注册；未初始化平台不允许注册。
- 慢 I/O：慢密码计算及真实 SQLite 写锁等待期间，健康检查在 0.5 秒内响应。
