# 飞书与 Lark 接入

## 已确认范围
- 网关支持飞书及 Lark 企业自建应用登录、部门与成员同步，复用现有组织预览、确认、权限和同步计划。
- 渠道机器人对齐现有渠道：长连接、私聊／群聊、默认项目、任务绑定、附件、主动通知、流式卡片及停止／确认／审核。
- 默认仅处理群内 @机器人；组织先支持手动与定时同步，不新增通讯录事件回调。

## 实施
1. 先补国内／国际域名、身份一致性、分页与部分权限、消息与卡片回调、隔离和慢 I/O 行为测试。

3. 实现共享飞书协议适配器，以两个渠道标识自动发现；复用现有路由、媒体和交互控制。
4. 补配置界面、来源显示、多语言键、依赖打包和技术文档。
5. 执行相关后端测试、前端行为测试和构建；真实租户配置与客户端渲染另行联调。

## 约束
- 所有网络和文件 I/O 异步隔离，慢网络配合健康检查 canary。
- 不能将受限目录中缺失的成员误判为离职；登录与通讯录使用相同稳定身份。
- 不改动已有未提交修改，不启动项目服务、不合并、不发布。
- 操作手册在合并交付节点集中更新。
