# 用户与设备外观偏好

设备共用已安装皮肤、语言包、制作会话和草稿；只将使用选择按已认证的网关用户与设备保存。设备后台为权威存储，浏览器缓存按同一身份隔离，换终端恢复服务端选择。本机未登录平台时继续使用原浏览器偏好，不迁移公共旧缓存到个人账号。

新增个人偏好 GET/PATCH 接口，身份只能来自认证上下文，字段为皮肤 ID、语言选择、字体类型和四档字号。项目只读访问也可修改个人偏好，不开放宿主包管理。启动先恢复身份与选择再挂载应用；预览不保存，确认保存；失效包使用默认回退。写入串行合并并提供失败重试。

测试覆盖账号/设备隔离、换浏览器恢复、重启持久化、预览取消、连续修改、保存失败、包失效及慢盘健康 canary。项目工作台提供独立外观入口，复用既有外观设置。同步技术文档与 Code Map；本批不合并或发布，不触发手册交付流程。
