# 流程钩子实施记录

采用统一 POST 路径 `/api/hook/{设备ID}/{钩子ID}`，网关、内网和外网地址按总配置分别生成。设备保存多个流程钩子，网关仅保存已有设备记录的安装身份映射并转发，不保存钩子配置或 Token。

配置页管理默认标题、默认创建者、阶段、启用状态、Token 及创建／运行方式；模拟页演示 URL 覆盖和完整 POST 正文。Token、设备标识、步骤与平台任务权限均由设备检查。

实现与验证细节见 [流程钩子技术说明](../docs/workflow-hooks.md)。第一版不包含平台事件提取、重复投递去重或设备离线排队。合并交付时集中补齐用户手册与固定演示项目真实截图。
