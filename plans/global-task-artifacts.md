# 全局产物实施计划

状态：已实现。交互原型位于 `tmp/global-artifact-prototype/index.html`，默认展示 A「独立区块」。流程编辑器实测原型位于 `tmp/global-artifact-prototype/editor.html`，默认展示已采用的树形连接线。

## 交互与行为

- 在流程编辑的每条输出配置上加「全局」复选框，默认关闭。所有宽度保持单行，顺序为「全局、名称、模板、类型、删除」。全局放在输出行的最左侧，用输出组原有缩进绘制树形连接线，标明各输出归属哪个输入。连接线仅用于包含子输出的输入组，独立输出不显示连接线。名称框吸收宽度变化，模板、类型和删除沿用现有规格。使用紧凑标签字号、16px 复选框和移动端 44px 触控区。
- 任务「产物」页在阶段分组上方显示「全局产物」。文件或目录只列一次，展示名称、文件名和更新时间，沿用现有点击预览与下载。该组没有轮次标签、分轮筛选或与上一轮对比。尚未生成任何全局产物时隐藏分组。阶段的输出列表保留对应条目，并以「全局」标记。
- 「全局」和「成功后复用」独立配置，可以同时开启。成功后复用继续决定何时跳过有可用结果的阶段。直接重跑仍执行该阶段，文件继续使用固定路径。其他阶段可以更新文件，更新内容不使声明阶段的成功结果失效；文件删掉或变空时仍按既有缺失产物行为提示重跑。

## 配置、路径与运行

- 在现有输出描述新增可选布尔字段 `global`，缺省等同于关闭。保存、导入、嵌套子输出、编译、任务草稿和运行快照保留该字段。已有任务内锁定的输出结构继续受原有契约保护。沿用现有数据格式，无数据库迁移。
- 通过项目数据目录解析 `artifacts/<流程ID>/<任务ID>/<声明阶段标识>/Global/<产物文件名>`，使用可见的 `Global` 子目录，和阶段下的数字轮次目录并排。文件扩展名和目录类型沿用既有规则。同一任务的首次执行、补充、重跑、返工与恢复使用同一路径。名称与路径解析拒绝越界、符号链接逃逸和解析后的路径冲突。沿用任务产物清理边界。
- 从本次编译的完整流程收集全局产物，在每个执行阶段的首次、重试和续聊提示中注入名称及固定路径，包含无直接连线的阶段。在固定路径尚未生成时也提供引用。声明阶段首次按输出模板创建，后续执行按指令更新已有内容，其他阶段只在其指令需要时写入。自动审核读取本阶段声明的实际输出路径。
- 全局可见性不建立调度依赖。显式正向连线仍随声明阶段通过及输出可用性激活，读取固定路径。步骤清单可记录该路径的引用，用于既有调度和恢复，文件本身只存一份。返回线以每次执行是否提交反馈为触发依据，共享文件长期存在会让该信号失真，因此全局输出接返回线时在编辑和后端校验中提示改用普通轮次产物。
- 首版沿用执行引擎直接读写文件。写入立即可见，阶段失败或返工不会回滚。多个会写同一文件的阶段通过正向依赖明确顺序，否则并行写入可能覆盖。步骤提示简短要求先读现有内容、保留其他阶段的改动。无需新建写入服务、锁或版本配置。

## 读取与兼容

- 产物列表通过稳定路径标识全局资源，并提供 `global: true`。没有产物轮次，旧接口需要数值时保留内部占位值，前端分组、轮次筛选、消息轮次标记和历史选择排除这类条目。任务详情和分享页共用同一投影，两者继续按任务授权预览、下载。共享内容更新沿用任务产物刷新信号。
- 普通产物继续使用 `<阶段>/1/`、`<阶段>/2/` 等目录。由系统标记阶段的 `Global/` 目录，旧版第 1 轮的检测和扫描仅排除已标记的目录；存在同名未标记目录时保留原数据并提示路径冲突。给既有输出开启「全局」后，从下一次按新配置执行开始使用固定路径，保留已有轮次与文件。

## 验收

- 后端先覆盖编译、旧流程、同名与路径边界、阶段下只有 Global 时不误判为第 1 轮。以受控引擎执行任务，验证未连线阶段收到路径、不同任务隔离、重跑与续聊复用路径、声明阶段通过后正向交接、返回线校验，以及「全局＋成功后复用」在文件已更新和已缺失时的行为。文件与数据库读取走既有执行器，并为新增阻塞路径覆盖慢 I/O 健康检查。
- 前端覆盖勾选保存、重新打开和嵌套配置同步，以及任务详情和分享页的全局产物预览、混合普通产物、有且只有全局产物、文件未生成与长名称。以实际组件在 320、390、1023、1024 和 1440px 渲染验收，完成 Web 构建并更新流程和任务 Code Map。
