# 动态语言包实施记录

已在 `feature/custom-skins` 实现 Runtime 声明式语言包：规范生成、校验、异步安装服务、项目权限、CLI、动态选用与缓存、预览确认取消、同一外观对话右侧语言分区。具体当前接口和限制以 [语言包规范](../docs/languages.md) 为准。

右侧使用“编辑与预览 / 语言”切换，字体仍在外观编辑控件内；移动端沿用聊天 / 编辑与预览 Tab。语言元数据和术语通过同一对话改文件，编辑栏只读取、校验、预览和安装，不重复实现草稿编辑器。刷新同时读取皮肤和语言目录，不创建会话。内置语言沿用原偏好；网关远程设备使用独立路径作用域。

第一版不提供独立语言中心、语言 onboarding 会话、按 revision 的额外下载接口、CLI ZIP 导入（使用界面）、完整 RTL、机器翻译质量认证或第三方日期控件的新增语言资源。语言包更新使用显式 replace；不承诺原方案中的 metadata expected_revision 编辑流程。

验证：后端真实 API 的权限与慢盘 canary、ZIP/JSON/占位符与关键提示校验；前端真实组件的自动重读、安装预览取消、词典回退、加载失败和竞态、去重及规范一致性。真实联调：2026-10-13，同一普通制作会话由 Codex 生成 Runtime `language/` 西班牙语示例包 spanish-demo；86/2963 条、全部5个关键提示与占位符通过后端校验。右侧轮次结束自动读取；浏览器安装预览、取消回到简体中文、再次预览确认、西班牙语第五选项与刷新后恢复均已验证。示例为部分翻译，不宣称全量西班牙语；当前界面优先在简体中文下继续评审。
