# 原型检查记录

已验证：

- 常规修改 → 当前草稿预览 → 客户搜索 → 模拟测试 → 固定镜像版本 → 发布 → 保留数据回退。

- 结构变更需要准备测试数据；隔离恢复完成后才允许测试；高风险发布须确认维护与恢复方案。
- 数据库结构不兼容时阻止直接回退；数据恢复需要独立输入确认，之后仅查看恢复流程。
- 健康检查失败不切换正式入口，重试可完成发布。
- 全量数据空间不足阻止准备，改用关联子集后可执行；取消任务不产生“就绪”数据。
- 名称必填与空白校验、SQLite 选择、运行脚本保存、Git 分析建议、域名状态保存。
- 320、390、1023、1440px 下五个功能页面与图表页无整体横向溢出；图表在局部区域滚动。
- 架构图三个视图、流程图五个视图的节点选择、说明与缩放；节点未超出图表边界。
- JavaScript 语法检查通过，浏览器未捕获页面脚本异常。
- 统一静态字号至项目设计规范中的尺寸；未添加设计检查忽略规则。
- 工作台模板包展示 6 条流程、6 个项目快捷按钮及 5 个对话快捷按钮。空项目不选择模板时不生成，主动应用后不自动执行；重复应用保留修改过的流程名称且不生成重复项。
