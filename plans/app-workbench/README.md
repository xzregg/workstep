[手机尺寸预览（390px / 320px）](mobile-preview.html) — 不用手动缩窗口，直接体验项目抽屉、打开应用、草稿／正式切换，以及配置 → 常规 → 应用初始化。默认框架为 FastAPI + Peewee + SQLite，提供 Node.js 框架模板方向。

当前确认方向（2026-11-07）：[沿用现有对话，新增右侧工作台](integrated.html)。桌面端工作台占整页 70%，左侧保留项目对话列表和当前聊天。A/B/C 是功能对话，共享同一个项目工作台与版本。

体验：分别在 A/B/C 发送示例 → 从任一对话创建版本并发布 → 顶部选择 Tag → 启动 → 分享。收起侧栏后恢复完整聊天区域；设置中可填写工作台目录（根目录 `.` 或子目录），保存后需要重新启动。全部执行均为模拟。

以下三个布局保留为早期比较稿，当前以 integrated.html 为准：

- [A：对话为主，右侧预览](layout-a.html) — 建议优先体验，最贴近现有聊天习惯。
- [B：程序为主，右侧对话](layout-b.html) — 工作台占据主区域。
- [C：对话与工作台页签切换](layout-c.html) — 避免同时展示两块内容。

三份原型均可体验发送示例修改、筛选客户、测试、创建版本、部署、版本预览与回滚。操作详情为浮层，Escape 可关闭。版本与部署均为内存模拟。可从左侧切换同一项目的两个对话，输入草稿分别保留。

原型无网络依赖，不访问真实数据、不执行脚本、不调用模型、不启动 Docker。状态只存在当前页面内存中，刷新或“重置演示”恢复初始状态。进度、容量、测试结果和耗时均为演示值。

建议体验顺序：

1. 默认“常规更新”：发送修改 → 启动预览 → 运行测试 → 创建版本 → 发布检查 → 开始发布。
2. 切换“大表结构变更”：在环境与数据中选择隔离库、准备数据，查看版本发布中的高风险检查。
3. 切换“数据量过大”：比较全量复制与仅结构／业务子集，观察数据准备状态。
4. 切换“发布失败”：完整走到健康检查失败，核对正式版本未切换，重试发布。
5. 切换“回退不兼容”：版本页回退 v1.1.0，查看禁止直接回退和独立数据恢复确认。
6. 切换“空项目”：查看工作台模板包，应用后一起生成 6 条流程、6 个项目按钮和 5 个对话按钮。重复应用不会重复生成；“查看流程与按钮配置”可修改项目流程名称。
7. 在开发页点击“梳理需求”，提示词只填入输入框，确认发送后才修改草稿；“创建版本”“发布上线”“切换版本”等项目按钮复用原有版本和风险检查入口。

智能接入原型：点击左侧项目“＋”→ 选演示目录 → 添加并分析 → 查看接入建议 → 绑定隔离测试库 → 确认方案 → 查看并确认验证计划 → 开始验证 → 查看生成内容 → 应用配置。已有 CI/CD 默认沿用，正式发布保持待接通。顶部可切换空目录、启动失败或现有项目配置入口。

本草案中的默认值和方案不是现有运行行为；真实实现前需补部署执行器、持久化任务和数据库适配验证。见 PRD 的待验证事项。
