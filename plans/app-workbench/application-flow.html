1. 配置应用

应用目录、模板、数据库与基础组件。新模板默认 Node.js + TypeScript；前端 React，后端 Fastify，数据库 SQLite 或 PostgreSQL。已有项目保留原技术栈。

↓

2. 自动准备，缺什么再补什么

检查 Git、运行时、端口与目录冲突 → 新项目生成骨架／已有项目分析启动与 CI/CD → 隔离依赖 → 准备草稿库 → 补齐流程与快捷按钮。

检测失败时停在对应项，可修正重试；不覆盖已有代码、流程或正式环境。以上准备步骤为设计流程，当前交互原型只模拟配置结果。

↓

3. 三栏开发

项目与对话列表 ｜ 当前聊天 ｜ 应用窗口栏

聊天修改草稿 → 启动草稿 → iframe 预览 → 测试。应用窗口栏顶部仅保留环境切换、版本摘要、发布与更多，底部无附加内容。

体验三栏应用 ↗
↓

4. 创建版本并发布

查看变更和测试结果 → 固定 Git 提交与 Tag → 构建镜像 → 检查数据库迁移风险 → 部署候选实例 → 健康检查 → 切换正式流量。

创建版本后可暂不发布；失败保持原正式版本。回滚先检查数据库兼容性。

↓

5. 使用、分享与继续开发

正式应用通过网关授权分享。后续聊天继续修改草稿，重复测试与发布流程。

基础组件如何接入

组件新应用模板已有应用
用户登录登录页＋会话接口；可配置网关身份映射适配现有登录接口，明确账号映射，保留原账号
角色权限 RBAC用户／角色／权限模型、前端权限控制、后端鉴权映射原有角色与权限，验证接口授权
统计图表组件＋事件约定＋统计接口适配业务指标与数据来源，不读取宿主私有统计库

组件是带版本的模块及适配契约。选择组件只生成接入计划，须完成接口、迁移与验证后才能启用。
