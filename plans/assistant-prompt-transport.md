# 助手提示词传输与查看方案

状态：普通对话、渠道对话、流程设计、任务创建／定时生成、任务协调和经验归档已接入。结构化响应修复、任务步骤执行与审核同步接入；既有步骤和审核配置中的 prompt 仍是本次任务要求。

## 统一边界

助手提供三类内容：固定角色与行为规则（instructions）、每轮重新获取的数据背景（turn context）、用户输入（user input）。用户气泡只保存输入和附件引用。按用户最新要求，所有已迁移助手查看仅显示本轮实际提供的输入；用户已确认将实际输入复用原有提示词字段存入数据库，不根据当前配置补造历史；已保存输入在重启或缓存淘汰后仍可查看，未记录过的输入不补造。引擎内置提示词由引擎管理，追加 WorkStep 规则而不覆盖预设。

ACP 基类是统一入口；这里的 system_prompt 是 WorkStep 扩展，并非所有 ACP Agent 都有同名原生协议字段。Codex SDK 使用 developer_instructions，Claude / Qoder SDK 使用预设 append，Pydantic AI 使用历史中持久化的系统消息，恢复时相同规则不重新注入，其余当前适配器只能正文降级。每轮提供参数不等于所有引擎都支持修改已恢复线程的系统消息；每个适配器仍需验证恢复后的有效行为。可选适配器调试快照不代表完整服务商上下文，也不是聊天查看的持久化数据。

建议固定规则放独立 instructions；会变化的执行数据保留为有明确数据边界的 turn context，默认不提升为系统级行为规则。渠道的来源元数据是已落地的特殊场景：本轮随独立指令参数提供，明确声明名称不是指令；不支持时每轮正文降级，查看中如实显示。后续建议把 instructions 和 turn_context 分成明确的统一输入结构，避免把稳定角色和变化背景绑定在同一个字段。

## 缓存约束

system/developer 的角色本身不禁用缓存，稳定的全局指令适合放在前部。每轮变化的来源、任务状态或时间若重写前部 system 内容，会降低后续历史的前缀复用；渠道已有实现不在本次普通对话迁移中调整，未来 turn_context 拆分应兼顾这一点。这里只验证输入是否稳定，不模拟或承诺真实服务商的命中率。

## 已实施的助手拆分

| 入口 | 独立指令 | 每轮数据背景 | 保持的用户输入 | 迁移要点 |
|---|---|---|---|---|
| 普通会话 `chat_session.py` | 项目配置的会话指令；未配置保持空值 | 跨引擎交接、需要重建的历史 | 最新用户原文 | 不自动添加现有常量默认角色；修改项目指令后标明生效轮次 |
| 流程设计 `workflow_gen.py` | 流程设计角色、输出 JSON 约束、稳定节点规则 | 当前画布、未保存修改、流程名称 | 本轮设计要求 | 画布每轮以最新版本为准；不能只在首次放系统提示词 |
| 任务创建 `task_draft.py` | 创建角色、提案格式、校验规则 | 可选流程、步骤、当前草稿和项目背景 | 创建或修改要求 | 创建与定时模式分别使用其角色，变更模式需更新指令或显式新建会话 |
| 定时任务生成（task_draft schedule mode） | 定时执行角色与结果约束 | 本次调度指令、候选流程、运行时数据 | 本次执行要求 | 不把上一轮调度实例当作当前事实 |
| 任务协调 `coordinator.py` / `coordinator_context.py` | 协调角色、动作提案与权限规则、输出结构 | 任务状态、步骤/审核轮次、产物索引、补充信息 | 用户原文或协调触发请求 | 当前恢复路径依赖已有线程背景；迁移时显式刷新变化数据，不能只拆首轮字符串 |
| 经验归档 `archive_experience.py` | 证据约束、经验提取规则与输出结构 | 本次任务、步骤、审核、消息与产物证据 | 归档触发请求 | 单次调用也走统一入口；保留停止、修复解析和日志路径 |
| 任务步骤执行及审核 | WorkStep 固定执行角色；审核只读角色及 JSON 输出约束 | 当前步骤、执行/审核轮次、前次失败、产物、补充材料 | 既有步骤和审核配置的本次任务要求 | 固定规则走 ACP 入口；原始恢复输入和实传查看记录分开保存，历史字段兼容 |

流程修补与结构化响应修复不是新的常驻助手，其格式约束可用独立指令，待修复内容和校验错误为该次调用的数据；迁移时一起检查辅助调用，避免主流程拆分但修复路径继续重复角色。

## 会话与轮次

固定规则在新会话首次提供；支持原生配置更新的适配器可在恢复时重新设置，不能通过重复历史消息模拟。动态背景每轮重新生成，与 Session ID 是否改变无关。无状态引擎每次需要角色、数据和必要历史；会话丢失或跨引擎切换需显式重建角色及历史。正文降级不可承诺用户原文就是模型看到的完整 user 输入，应在查看中展示完整实际正文。

## 实施状态

1. 普通会话（已接入）：复用统一入口和共享本轮实际输入的持久化查看；固定全局规则独立提供，原生/正文降级、新建/恢复、原文和慢提示词读取 API canary 已验证。指令修改/清空后旧线程的有效行为仍须按适配器验证，正文降级旧线程不会自动撤销历史指令。
2. 流程设计与任务创建（已接入）：引入稳定指令/动态数据/用户输入结构，迁移两者及定时模式。
3. 任务协调（已接入）：补齐每轮数据刷新，再迁移经验归档及修复辅助调用。
4. 任务执行与审核（已接入）：固定执行规则及审核角色／结果格式单独传入，步骤与审核要求仍是正文；通过统一入口记录首轮、恢复和重试的实传输入，不重写既有工作流提示词。

每一阶段独立验收：聊天气泡原文、查看的实际输入、原生/降级差异、第二轮数据变化、会话隔离、恢复/重建/重试、停止和结构化结果。涉及配置或数据库读取时继续用慢 I/O 健康检查确认事件循环响应。现有历史 prompt 保留原样，查看中不能伪造过去请求。

## 待确认的产品选择

建议采用：固定规则独立指令、动态任务数据作为独立背景区、用户原文单独保存；不支持的引擎允许明确正文降级。步骤 prompt 暂时作为用户任务要求，不擅自转成 system；项目系统指令修改从下一轮起生效，但不支持恢复更新的引擎需要明确提示或新会话。以上入口均已接入；未新增工作流模板字段。


## 实际输入查看

`AssistantConfig.system_prompt_transport` 让共享运行时独立提供固定指令，任务创建按普通／定时模式选择规则。按最新确认，持久化助手将完整实传输入复用原字段保存：普通／渠道为 `chat_messages.prompt`，流程为 `gen_sessions.messages_json` 中消息的 `prompt`，任务协调及经验草稿为 `messages.prompt_json` 的 `prompt`。协调在捕获时通过项目执行器写入，普通／渠道／流程使用既有会话持久化适配器；经验草稿生成完成后随消息保存。运行时缓存用于实时查看，历史优先使用已存记录，不依赖当前配置。重试与辅助修复按实际调用依次展示；失败前尚未调用引擎时不合成预览。内部输入事件不重复进入过程日志。任务创建／定时生成会话仍默认仅内存，任务步骤与审核的恢复检查点保留。

协调角色和权限由助手上下文层统一提供，ACP 输入捕获路径不再额外拼接一套规范；未捕获的旧底层调用保留 guard 兼容。动态任务快照即使恢复同一会话也重新获取。任务步骤在 `messages.prompt_json`、审核在 `review_runs.prompt_json` 及对应 `messages.prompt_json` 中保存：`prompt` 是实传查看文本，`input_prompt` 是恢复／重试使用的原始输入。旧记录缺少 `input_prompt` 时继续读取原 `prompt`；新的查看格式不会被重新当成执行合同传入。未开始调用时仅保存检查点，不展示合成的实传预览。

验收：`test_workflow_gen.py`、`test_task_draft.py`、`test_coordinator.py` 覆盖原生 system/developer 与正文降级、第二轮背景、格式修复、数据库查看、重启后恢复实际输入、无重复日志输入副本及已有停止、慢数据库健康检查；`test_review_gate.py` 覆盖执行／审核的 system、developer、正文降级、同会话打回重跑、原始检查点恢复及慢输入保存健康检查。

任务 Git 工作区规则已拆分：Git 命令执行位置、仅添加任务所需仓库、项目相对路径及 `git worktree add --relative-paths` 放在稳定的执行系统规则中，仅在提供工作区背景时适用；任务专属的工作区相对路径也通过 `assemble_step_system_prompt` 绑定到系统规则，挂载仓库列表继续作为正文背景；正文中保留已有工作区快照用于恢复检查点和变化检测。

Pydantic AI 固定系统消息随 Harness 历史保存并在压缩时保留；恢复相同规则时只传新正文，规则更新、清空或历史丢失时由引擎替换／重新初始化自己标记的系统消息。Codex SDK 仅在原生最新 turn_context 保存的 developer 指令（含自定义配置）与当前规则一致时省略线程覆盖；旧版本或历史缺失继续设置。Claude/Qoder 当前每轮启动新进程，保留 preset append；支持系统参数不等于支持恢复该参数，不能用 Session ID 一概跳过。
