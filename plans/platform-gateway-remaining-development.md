## 批次 4：分级管理范围验收（2026-10-03）

- 新增组织、部门、设备管理员角色；组织范围绑定身份源，设备范围绑定显式设备组或设备部门。迁移 `0035_device_management_scopes` 保留原设备、已发布项目和授权，未归属设备不会凭用户部门自动进入部门管理范围。
- 用户/目录、设备审批与停用、批量作业、已发布项目、整机授权、用户/组 task.create、供应商分配和审计查询均按其管理角色作用域检查。管理权限不产生普通设备或项目内容授权；已有用户组的组长/目录只读成员规则保持独立。
- 组织管理员可在本组织内委派、调整和撤销部门范围的身份、部门及审计角色，不能委派平台角色、跨组织或修改超管/恢复权限。门户按角色提供模块入口、真实范围选择及二次认证；供应商分配复用原组件，分级管理员不能读取全局连接配置与统计。
- 新增多角色组合回归：全局身份管理员不扩大部门的项目/供应商授权；重叠的递归和非递归部门角色取并集，与查询顺序无关；混合范围设备作业被拒绝，范围外作业与审计不出现在列表。

## 批次 5：身份与操作审计验收（2026-10-03）

- 任务创建、流程分发创建、复制、归档、恢复和删除在项目数据库执行器内与审计同事务提交；审计失败回滚任务/步骤状态。创建与复制记录实际操作者，消息作者、模型作者、任务发起人和定时执行发起人保持各自已有快照规则。
- Gateway 管理请求的 CSRF 拒绝、校验失败和服务端异常记录 `request.denied/failed`；只保存已认证身份、HTTP 方法、路由模板与状态，不保存路径参数、查询、正文或异常内容。数据库不可写时记录脱敏日志收据，保持原响应。
- 远程项目的越范围/只读/宿主文件系统拒绝与处理失败写到可信票据绑定的项目，绝不使用请求中的其他项目 ID；记录用户/设备快照且不记录被尝试访问的其他任务 ID。已有本机执行、恢复、暂停、审核与定时规则事务审计和 Gateway ACK 后上传规则回归通过。
- 修复自动启动创建后同步读取任务的问题，改为项目数据库执行器。新增慢审计 SQL、创建后慢读取、远程拒绝慢写入和 Gateway SQLite 写锁健康检查，均保持轻量健康接口可响应。
- daemon 身份/消息/创建/运行/归档/定时/真实项目代理与安全相关回归 228 通过；新增审计 canary 单文件 3 通过。Gateway/协议全量 215 通过、1 跳过，随后新增 Gateway 写锁 canary 专项 2 通过。企业微信/钉钉真实跳转仍按用户要求暂缓。

## 批次 6：调用授权与账本核心验收（2026-10-03）

- 远程 HTTP/WS 将当前访问用户的供应商范围和五分钟期限传给 PC，不能借宿主登录用户的供应商调用；本机有效策略与访问用户范围同时生效。轻量 HTTP 调用重查配置，过期、撤权、密钥轮换后的缓存凭据在网络请求前拒绝。未分配供应商不回退原生凭据；OpenClaw、Qoder SDK 和 Cursor SDK 的原生凭据调用在受管模式下拒绝，Hermes 通过共用运行时解析拒绝。
- 用量与审计共用组织/部门/设备组范围，范围报表使用包含原始发起人的事件，聚合完成后仍不扩大范围；审计角色仅查看与导出当前授权页，不能导入全局账单或查询全局对账。已有账单幂等导入、差异对账和汇总重建测试通过，未知用量不当作零。
- 用量数据库初始化、实际调用前配置读取和一次性调用身份读取均进入工作线程，慢磁盘/配置 canary 通过。签名 Skills 部署后进入真实 Codex spawn 适配器，授权白名单进入实际启动参数；未执行外部模型推理。
- Gateway/协议 219 通过、1 跳过（无真实 PostgreSQL 地址）；门户 79 通过及生产构建通过；daemon 供应商/调用/Skills/用量/引擎专项 110 通过，Git/协调器/聊天/执行审核回归 281 通过。修正测试中共享 /tmp 技能目录与全局默认供应商造成的环境污染。
- V1 不自动删除用量、审计、账单与幂等收据；仅处理后清理聚合队列，备份归档保留原始记录。供应商自动拉账仍留到 V1 之后。互动分享的模型授权与统一任务详情随批次 7 联验，因此尚不宣布原正式阶段全部交付。

## 批次 7：恢复、容量与统一分享验收（2026-10-03）

- Gateway 分享入口加载原 WorkStep Web 的独立构建，删除门户中重复的任务、聊天、审核、交互、消息/产物和 Git 组件；会话、历史翻页、展开事件、重试、刷新恢复与撤权清理由原 `useSharedTaskSession` 持有。没有公共分享 WS 时串行轮询任务快照，保留已加载的历史与事件，切换分享后旧请求不会覆盖新内容。
- 复用原 `TaskDetailPage`、聊天、审核确认与交互表单；服务端复用任务、历史、执行报告投影。Git 补任务限定历史、差异、远程分支元数据和虚拟目录，隐藏宿主路径、远程连接地址、隐藏文件及越界符号链接。共用控件只显示已接通操作，分享不提供工作区增删、凭据设置、合并/恢复或文件编辑；本机已有能力保持默认。
- 互动票据绑定创建者当前供应商范围与五分钟上限，帧不能覆盖。真实 ASGI 桥中的供应商检查允许签名范围并拒绝宿主专用供应商，操作者仍是 `share:<id>`。创建者停用、分享权限与供应商撤权会拒绝或终止请求；整机 HTTP/WS 补与项目流一致的授权复查。
- 容量测试复现并修复异步授权等待后的并发竞态：33 个同时等待的请求只允许 32 条流，超额拒绝，结束后全部释放。已有 HTTP/WS 分块与双向窗口流控、真实进程中断恢复和命令幂等回归通过；实际受管包网络容量基准仍在批次 9。
- Gateway/协议 224 通过、1 跳过（无 PostgreSQL 地址），随后新增慢分享入口磁盘 canary 单文件 3 项通过；daemon 分享、命令、恢复与桥接/控制客户端共 88 通过。门户删除重复功能后 72 通过；WorkStep Web 全量 1091 通过。门户、原 Web 与独立分享构建通过，原 Web 仍有既有大分块提示。
