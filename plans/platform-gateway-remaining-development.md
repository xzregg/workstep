## 批次 2：完整工作台复用验收（2026-10-03）

- 项目子域的页面和构建资源经已认证数据连接转发到宿主的完整 WorkStep Web；共享允许路由只增加明确的工作台页面与公共资源，管理页面、全机项目列表、系统设置、隐藏文件和路径穿越仍拒绝。
- Web 先载入共用远程会话，再读取绑定项目摘要。项目 store 只保留该项目、不暴露宿主路径，清除旧项目选择并进入原任务路由；Layout 不重复初始化请求，原 WebSocket 订阅携带绑定项目 ID。会话丢失立即卸载内容，阻止在失效会话下继续展示工作台。
- 删除 Gateway 中简化的 ProjectWorkspacePage 及重复 ProjectAccessSettings；任务详情沿用原 TaskDetailPage，访问授权复用原 ProjectPublicationSettings，平台分享入口迁入原 TaskDetail 的独立 GatewayTaskShareLink。旧组件的权限和交互测试迁至真正持有行为的 Web 模块。
- Gateway/协议全量 201 通过、1 跳过；daemon 数据桥 8 项通过，新增真实 StaticFiles/FileResponse 路径含慢盘健康检查通过；Web 全量 1079 通过，随后新增实际 App 装配测试 1 项通过；门户全量 71 通过。两个 Web 构建通过。
- 这里只验收工作台复用、初始化及现有入口迁移；更多项目配置/模型目录接口、只读控件行为在批次 3/6 完善；真实受管安装包与页面尺寸/容量验收仍属于批次 8/9。

## 批次 3：项目隔离与只读验收（2026-10-03）

- 补齐绑定项目的引擎、执行默认值、协调器、助手及供应商目录读取；Web 统一补项目查询参数并拒绝跨项目，daemon 再校验可信操作者。只返回能力/schema 与可用供应商的公开目录，不返回宿主路径、安装命令、配置值、连接地址或密钥。项目模型查询只读缓存，禁止刷新宿主目录并隐藏底层异常。
- 修复授权创建任务后复制任务仍被拒绝的问题：创建与复制共用 task.create 校验和流式重新授权。只读工作台限制任务创建、运行、归档、删除、拖动、侧栏管理、画布保存、目录编辑及聊天/审核/交互写入；保留历史、产物、文件、已归档任务和流程查看。
- Gateway/协议全量 207 通过、1 跳过，含项目 HTTP 流与 WebSocket 撤权关闭；daemon 项目/文件/工作台真实代理 20 通过，目录与聊天专项 4 通过，助手/引擎目录相关 89 通过。Web 全量 1083 通过，生产构建通过。慢配置、慢文件与慢 SQL canary 证明健康检查仍可响应。
- 宿主全局管理、安装、密钥读取接口继续不进入项目路由目录；模型调用与供应商细粒度策略按批次 6 验收。企业微信/钉钉真实跳转、实际安装包与窄屏视觉验收仍留在后续批次。
