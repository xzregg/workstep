## 目标与分期

- 在共享 ChatInput 中提供语音转文字，支持 PC 麦克风入口、移动端长按切换语音输入，转写只进入草稿，用户手动发送。
- 完整方向保留本地与云端两种识别方式、当前对话上下文与项目词库；先交付可用的轻量本地链路，再扩展模型和联想。
- 当前默认为 Streaming Paraformer 三语版 INT8，通过 sherpa-onnx OnlineRecognizer 运行，支持普通话、粤语、英语自动混合识别。资源约 227.5MiB，不包含运行库。旧 SenseVoice 目录保留，但新模型须单独下载；旧强制语言设置恢复自动。
- 第一期只展示一个真实可下载、可运行的模型；不展示无法使用的模型按钮。第二期接 Qwen3-ASR 和一个云端适配器，具体版本以平台验证结果确定，不把云端全部能力宣称为本地可用。
- 当前 worker 在整条录音中复用编码器／解码器缓存，仅输入新增音频，临时结果覆盖旧假设；松手补入尾部静音并 input_finished 刷新余量，不反复识别累计音频。分句端点可重置内部声学状态并保留已完成文字。

2026-11-09 交互与标点补充：录音激活后滑动不取消，松手完成；麦克风已启动但会话仍在连接时保留并定稿已有音频。最终帧与在途预览响应并行传输，后台有序处理并校验归属。停顿分句与最终定稿使用 CT-Transformer 中英文 INT8 标点模型（75,519,198 字节），既有 ASR 无需重下，补充下载时校验并复用已有资源；下载失败／取消继续保留原 ASR。标点资源哈希已与官方 sherpa-onnx release 对照；[官方说明](https://k2-fsa.github.io/sherpa/onnx/punctuation/pretrained_models.html)。验证：后端相关 90 项、Web 相关 41 项通过，Web 构建通过；320／390／1023px Chrome 移动触摸事件验证滑动继续录音、松手定稿，采集使用替身，Android 实际麦克风仍需复测。新增标点文件已校验并安装到本机现有语音资源目录，未重启应用服务。本机真实粤语 5.976 秒样本定稿为“有无人知道湾仔活道系点去？”，最终解码与标点约 23ms，含冷启动全段计算约 629ms、复用进程约 143ms；不包含网络与真实采集耗时，不能视作手机性能承诺。

## 设置与交互

- 设置导航增加「语音输入」，由独立 VoiceInputSettings 模块管理，SettingsPage 只负责装配。
- 页面包括：启用开关、当前模型、服务状态、语言偏好（自动／模型支持的语言）、模型列表、麦克风测试。未安装时关闭录音能力，点击入口引导到该设置并保留草稿，不自动下载。
- 模型行显示名称、支持语言、下载大小、安装占用、平台支持、状态；提供下载、取消下载、失败重试、设为当前、删除。安装包含匹配版本运行库，下载前展示总大小。下载进度来自实际字节，不模拟进度。
- PC：草稿编辑态在发送按钮左侧显示麦克风，空草稿和已有草稿都可用；点击开始，再点完成。已有发送／停止生成按钮保留职责，语音停止使用独立控件。运行中仅在既有输入权限允许时开放语音。
- 移动端：持续长按输入区域 500ms 切到语音模式，已有草稿和已聚焦输入框均可触发；达到阈值前移动超过 10px 或取消触摸时撤销；进入录音后滑动持续采集，松手才完成，浏览器滚动产生的 pointercancel 不再取消录音，系统 touchcancel 会结束采集并定稿已有音频。按用户修订，输入框不显示麦克风图标，长按优先切换语音而非打开原生选词菜单；普通点击与光标定位保持原生行为。长按达到阈值即进入语音模式并申请麦克风、开始录音，无需再点「开始录音」；松手即结束采集并恢复键盘输入框，转写完成后填入草稿；麦克风已就绪时，即使会话连接未完成，松手也会保留音频并等待定稿；仅授权仍未完成时松手取消，触摸被系统取消时定稿已有音频，显式取消、换会话或切后台仍丢弃。
- 录音区显示真实音量、时长、暂定文字与完成／取消。处理时显示旋转图标，未录音时不显示录音动画。单次录音上限先定为 2 分钟，达上限自动停止识别但不发送。
- 暂定文字保存在独立录音缓冲区，完成后按开始时光标插入草稿，不覆盖其他文字或附件；取消只丢弃本次录音。录音期间通过 readOnly 冻结正文编辑，保留原触摸目标的 DOM、布局和启用状态，不再隐藏／disabled 输入框或主动 blur，仍可取消恢复。失败时提供保留已识别片段或丢弃，不能把不完整结果伪装为成功。
- 语音会话绑定项目、会话／任务、草稿版本和唯一请求 ID；切换会话、关闭面板、页面进入后台时停止采集并取消会话，忽略迟到事件。麦克风轨道始终在结束／异常路径释放。

## 服务与部署

- 语音是应用管理的独立能力，不要求用户手工运行服务。默认由 daemon 按需拉起最多 4 个语音 worker，通过进程管道传输有界音频帧与事件，不另开 HTTP 端口。
- worker 独立加载模型、执行识别，首次调用显示加载中；保持热状态，最后一个会话结束后闲置 5 分钟退出，daemon 关闭时清理；崩溃后当前录音报错，下次调用重新启动，不无提示重录。
- 每台主机默认最多 4 个活跃录音识别会话，每条录音使用独立识别进程与缓存，按用户、项目及录音 ID 核权；同一用户也可并发不同会话。超过容量明确拒绝，取消／崩溃不影响其它路；空闲 worker 可复用且 5 分钟后释放。每路独立加载模型，CPU／内存占用随并发数增长。
- 桌面基础包只携带控制逻辑；模型与匹配运行库按系统／架构下载到宿主配置目录下独立语音资源目录，支持 WORKSTEP_CONFIG_DIR。固定清单记录版本、平台、来源、许可、哈希与文件大小；临时下载、校验完成后原子启用，失败文件不得标记为已安装。
- 模型与运行库版本共同校验。使用中模型不得删除或切换；磁盘不足、下载中断、架构不兼容均给出可恢复错误。常规应用升级不重复下载未变更模型。
- 手机浏览器采集音频，传给当前 WorkStep 主机识别；这里的「本地」指宿主主机，并非手机离线识别。需要支持麦克风的安全上下文；不安全 HTTP 环境显示原因，不尝试绕过浏览器权限。
- Electron 仅为可信应用页面开放音频采集权限；macOS 首次录音通过 systemPreferences 显式请求系统同意，系统拒绝／受限时不授予网页；Windows 检查系统麦克风状态。macOS 包含用途说明与音频 entitlement，系统弹窗期间离开原页面则不继续授权。若 daemon 在容器／虚拟机，第一期 CPU worker 随该宿主运行；Mac 原生 GPU 推理需后续单独接宿主桥，不能假设容器能访问 Metal。

## 模块、接口与权限

- 前端录音、音频转换、会话状态由 useVoiceInput 与独立 VoiceInputControls 持有；ChatInput 仅装配，所有入口通过同一能力配置接入，不复制录音实现。
- daemon 增加独立 speech 服务层：模型目录与下载管理、worker 生命周期、识别适配器、上下文构建。语音不是对话 LLM 引擎，不继承整套工具审批／任务执行协议。
- REST `/api/speech` 提供能力、设置、模型列表、下载／取消／删除、当前模型选择、服务状态；模型管理仅宿主管理权限可用。项目词库第二期通过项目范围接口管理。
- 独立鉴权语音 WebSocket 提供 start、音频帧、finish、cancel；返回 loading、ready、partial、final、error、closed。所有结果携带录音 ID 和递增序号；音频使用二进制帧，控制消息使用 JSON，限制帧大小、总时长和积压队列。
- 复用现有访问身份与项目授权，语音输入要求对应会话的编辑权限；只读分享隐藏入口。移动网关使用受鉴权的音频转发通道，权限撤销立即取消；不能把音频发到通用广播总线。未接通网关转发前不可宣称移动远程入口已可用。
- 文件、下载、推理及数据库操作不得阻塞事件循环；项目上下文与词库数据库操作通过 run_db 完整物化后返回。音频仅暂存内存，录音结束释放，不进入消息历史、普通日志或草稿持久化。

## 上下文与联想（第二期）

- 只取当前有权访问的对话最近 10 条消息（总计最多 4000 字）、当前草稿和项目词库；不搜索其他项目，不使用工具大段输出或附件全文。
- 支持热词／上下文的模型在识别前传入裁剪后的提示；不支持的适配器如实声明，不伪造能力。默认流式 Paraformer 当前保证基础转写，不承诺通过热词增强识别。
- 识别后联想展示原词和候选，仅修改用户确认的片段，可撤销；用户主动「记住此词」才存入项目词库，可查看和删除。不从每次编辑静默学习。
- 数字、否定、文件路径、命令等不得无提示自动替换。没有有效候选时保留原文，不为展示功能强造建议。
- 本地识别不得隐式调用云端纠错。第二期如需模型纠错，单独提供关闭／本地／云端选项及真实可用配置；云端明确展示会发送音频和选定上下文，凭据只由 daemon 保存。

## 实施顺序与验收

1. 先做模型与运行库打包验证：桌面目标平台 CPU 识别、粤语／英文专名混说、分段边界去重、内存与持续吞吐。记录实际下载量、冷启动、首段文字、结束到定稿时间；没有实测不承诺毫秒级体验。
2. 测试先行实现模型管理与 worker，覆盖下载取消／校验失败／磁盘不足／进程崩溃／并发录音／闲置释放；用慢 I/O 与识别进程负载配合健康检查 canary。
3. 接设置与共享输入框，覆盖长按与滚动／文本选择冲突、权限拒绝、草稿插入／取消、会话切换、迟到结果、附件与 IME、发送和停止生成不受影响。
4. 完成移动端安全连接和网关转发验收，检查 320／390／1023px、真实 iOS Safari／Android Chrome 与 Electron 麦克风权限。不可用平台显示真实状态。
5. 第二期增加上下文、词库、候选确认、Qwen 和云端适配，测试跨项目隔离、提示词误导、无云端配置时不外发及纠错撤销。
6. 目标为热启动后首段文字约 1 秒、停止后约 2 秒定稿；作为测量目标而非已满足承诺。报告每个平台的中位数和 P95，持续输入不积压为发布条件。
7. 同步 docs/code-map.md 和中文文案及全语言键集合；合并到 main 的交付节点再集中更新手册、译文与演示截图，运行手册检查。

### 原生流式默认模型修订

- 音频每 0.5 秒上传，worker 持续向同一个 OnlineRecognizer stream 输入新增样本，返回完整临时结果；结束时刷新模型尾部，替换为最终结果。
- 准备阶段保留最多 4 秒音频；慢识别时合并积压帧，每次最多 2 秒，避免逐帧追赶旧结果。
- 默认模型为 Streaming Paraformer 普通话／粤语／英语三语 INT8（immutable revision `86931b152d37c908528b44d30b431c24a19770da`），音频与解码状态仅保留内存。SenseVoice 旧资源不自动删除；下载入口安装新资源，旧日语／韩语等选择迁移为自动，当前不声明支持这些语言。
- 临时验证目录中真实粤语样本 5.976 秒连续分块：文字在 2.0、2.5、3.5、4.0、4.5 秒音频位置持续增长，最终为「有无人知道湾仔活道系点去」；首次 worker 请求约 0.43 秒，热请求通常约 0.01～0.02 秒。连续两次录音结果一致且无串入。该结果仅为本机 CPU 单样本，不是移动端端到端延迟承诺。
- 模型来源和转换 README 随资源下载，使用说明链接指向上游；不得将运行库许可直接当作模型许可。重启后台后默认切换生效，新模型必须通过设置下载；真实手机采集与网关延迟仍需验收。

### 准备等待与并发隔离修订

- 先申请麦克风，再等待 Web Audio 恢复；不在麦克风前等待可能受自动播放策略挂起的 resume。界面区分启动麦克风和准备服务，分别设置 30 秒与 15 秒超时，识别响应 20 秒超时，失败后可直接重试，迟到的设备／会话结果单独回收。
- 取消前次创建请求时保留迟到 ID 清理能力，但移除前端全局串行队列，一路挂起不阻塞其它会话。
- 服务使用最多 4 个独立运行进程，各进程独立管道、解码器和缓存；正常结束可复用，取消、超时、崩溃只释放本路。API 校验身份、项目和录音 ID；前端校验返回 ID、序号和结束标志，不把未知响应写入预览或草稿。
- 真实模型双路并发样本验证：Alice 粤语连续出字，Bob 静音全程空结果；实际子进程／HTTP 测试验证慢路不阻塞另一条录音或健康检查、跨用户访问拒绝、单路取消与崩溃不影响另一路。
