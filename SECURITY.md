# Security policy

Do not report vulnerabilities in public Issues or Discussions. Use GitHub **Private vulnerability reporting** on the Security tab and include the affected version, impact, reproduction steps, and any mitigation. Remove tokens, personal paths, project data, and secrets from evidence.

During the early project stage, only the latest release and default branch receive fixes. We will coordinate remediation privately and credit reporters when requested and safe. Security issues in third-party engines or hosted services should also be reported to their vendor.
