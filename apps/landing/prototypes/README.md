# 引导式教程动效原型

用浏览器直接打开 [guided-demo.html](guided-demo.html)，无需启动服务或安装依赖。该页面独立于官网生产入口。

约 32 秒连续录屏包含四个章节：查看流程、新建任务、补充说明、保存查看。支持暂停、重播、拖动进度条和点击章节跳转。

真实操作铺满背景。镜头按操作时刻平滑放大、平移到步骤配置、任务标题、说明与保存结果，最高放大到 1.7 倍。左侧渐变遮罩留出讲解空间，将录屏中的当前操作移到右侧，避免焦点压在说明文字下面；呈现大标题和四条勾选说明，条目按时间逐条浮现，已出现的内容累计保留，进入下一章节才切换整组说明。手机将讲解放在录屏上方，避免遮住操作内容。

`media/workstep-tutorial.webm` 是对 `http://127.0.0.1:8777` 隔离演示环境的真实界面操作录制，使用固定“操作手册演示”项目。录制过程实际打开步骤配置、填写标题和说明、选择手动开始、创建任务，并打开新保存的任务详情；没有调用 AI 引擎。鼠标指针和点击光圈依据真实鼠标事件显示。`media/recording.json` 记录素材尺寸、时长与章节时间点。

镜头和左侧说明由 HTML 渲染，直接跟随视频的 `currentTime`，暂停和跳转时保持同步，向前或向后拖动会重建对应时刻的步骤展开状态。系统开启减少动态效果时默认暂停，关闭镜头缩放及文字过渡。播放器不会连接或操作演示后台；网页可离线播放。

深色紫色舞台用于探索用户提供的参考风格，不修改官网的全局设计系统。移动页面时请一并保留旁边的 `media/` 目录。
