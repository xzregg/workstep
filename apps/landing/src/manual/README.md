# 操作手册维护与截图记录

截图保存为 `screenshots/<章节声明的ID>.jpg`。统一复用本机 `8777` 端口的“操作手册演示”项目，配置与固定目录见 `docs/manual-demo.md`，截图只保留相关面板，不包含密钥、个人对话、私有项目或内部服务地址。截取已安装、空白配置、待确认等状态时，说明必须对应实际状态，不能描述为操作已完成。

本轮已真实验证 SDK 双步骤执行、生成计划和操作说明、人工审核、无效模型报错、AI 流程提案、Git 独立工作区，以及隔离环境中的项目数据迁移和切回。机器人、分享、远程和定时设置使用未提交的配置表单；没有发送渠道通知或开放新访问。

截至 2026-10-11，本轮以本地 `main` 的 `5c857ce5` 为核对基线（v1.0.11 后续已合并修正），不把 `dev` 未合并或未提交的功能写为当前已支持。已核对流程触发／通知钩子、项目分享、网关设备页面记忆、项目排序、模型目录刷新与桌面目录打开行为，并修正默认设置按钮为“保存默认值”。
