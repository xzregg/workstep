WorkStep 隐私说明

WorkStep 桌面应用不包含使用行为遥测。项目、任务和执行数据默认保留在你的设备上。官网仅在维护者配置 Cloudflare Web Analytics token 时收集聚合访问量；该服务不使用跨站跟踪 cookie。GitHub 会按其自身政策记录仓库访问和 Release 下载。

远程分享和第三方 LLM 引擎是用户主动启用的功能，数据处理受对应服务条款约束。不要在公开 Issue 中提交密钥、私人项目内容或个人路径。

Privacy notice

The WorkStep desktop app contains no usage telemetry. Project, task, and execution data stays on your device by default. The website records aggregate traffic only when maintainers configure Cloudflare Web Analytics; it does not use cross-site tracking cookies. GitHub records repository traffic and release downloads under its own policies.

Remote sharing and third-party LLM engines are opt-in and subject to their providers' terms. Never post credentials, private project content, or personal paths in public Issues.
