# WorkStep Android

Android 应用通过 HTTPS 加载现有 WorkStep 移动端网页。第一次打开时输入服务根地址，例如 `https://workstep.example.com`。连接成功后地址保存在本机。短按悬浮球切换网页的项目、会话和流程导航菜单的开关；长按打开修改地址、重新加载和清除网页缓存三个选项。悬浮球可拖动，位置会保存在本机。应用离开至少 5 分钟后返回才自动重新加载当前页面；重新启动时加载上次访问的同一服务页面。文件选择和保存完成后不会重新加载。清除缓存会保留登录 Cookie、本地设置和服务器地址。

## 服务要求

- 手机浏览器能访问该地址；同一域名和端口提供网页、`/api` 与 `/ws`。
- HTTPS 证书须被 Android 系统信任。应用拒绝 HTTP、证书错误和混合内容。
- 电脑端默认后台只监听 `127.0.0.1`，不能直接作为手机连接地址；需另行部署可从手机访问的 HTTPS 入口。

## 构建

需要 JDK 17 或更高版本及 Android SDK 35。设置 `ANDROID_HOME` 后，在此目录运行：

```bash
./gradlew testDebugUnitTest assembleDebug
```

生成的调试包在 `app/build/outputs/apk/debug/app-debug.apk`。发布包需要另行配置签名；不要分发调试包作为正式版本。

## 应用行为

首次填写地址会请求 `/api/health`，确认是 WorkStep 服务后才保存。应用沿用网页的登录、接口和实时连接；返回前台时通知网页恢复 WebSocket，重新订阅并补回当前对话漏掉的消息，后台超过 5 分钟仍按原规则整页刷新。网页也在页面可见、网络恢复或浏览器历史恢复时重新连接，并用心跳识别失效连接。同一服务的页面留在应用内，外部 HTTPS 链接交给系统浏览器。“添加图片”优先使用系统图片选择器，普通附件使用文件选择器；网页下载会打开系统“另存为”界面，可选择位置和文件名。这些操作不需要存储权限。断网时可重试或修改地址。
