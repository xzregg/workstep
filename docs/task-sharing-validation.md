## 修复与回归

- `api/platform_share.py` 保留目录产物类型，审核列表复用任务详情的完整 `task_reviews` 投影。
- 目录浏览使用 `artifact:<id>` 的任务授权标识；目录内预览/下载按该目录限制路径，拒绝跨任务、路径穿越和目录外符号链接。目录本身不能作为文件下载。
- 分享的只读、可编辑入口均增加目录点击与子文件预览行为测试。
- 移除 BOT 后台定时读取与分享额外拉取项目任务列表。空闲轮询保持每 30 秒检查任务、历史、审核和产物，隐藏标签暂停；不能仅凭任务记录未改变而跳过独立文件/审核变化。
- `SharedEditableTaskDetail.tsx` 保持文件加载和目录浏览回调稳定，修复每次快照更新导致预览重新加载。测试先复现同一预览被请求两次，再验证刷新后仍只请求一次，覆盖只读和可编辑分享。
- 空闲、暂停及已结束任务不受残留步骤运行状态影响；协调助手运行期间仍每 2 秒检查。分享写操作成功后立即刷新快照并重新安排轮询。
- 任务说明更新发布 `workstep.task_updated`，原任务 store 只刷新变更任务；分享会话同时处理该通知。真实 API 测试覆盖事件、状态订阅和慢数据库健康检查。
- 网关分享创建与列表返回统一 UTC 时区，修复重新打开后有效期显示偏移 8 小时。

验证结果：daemon 分享与桥接专项 43 项通过；Web 分享专项 24 项通过；网关分享及数据代理专项 30 项通过；网关分享前端构建通过。最后增补状态及订阅断言后，对应 Web 10 项、daemon 3 项复跑通过。真实桥接测试包含慢 SQL/磁盘健康检查，以及审核完成后仍可读取审核结果。

## 网关分享 WebSocket 接入（本次后续修复）

先前降低轮询频率没有消除周期性的四接口请求，本次改为实际接入实时通道：

- 浏览器连接 `/api/public/shares/{token}/ws`，使用访客 cookie 并校验 Origin；不携带拥有者凭据或将 CSRF 值写入 URL。
- Gateway 复用现有数据连接转发到宿主 `/ws/platform-share`，签名票据限定分享、设备、项目及任务；连接期间复查分享权限，撤销、过期或模式变化关闭连接。
- daemon 验证固定公钥签名，拒绝将分享票据用于拥有者通道、附加项目/供应商授权或查询参数。两个分享入口共用 `_serve_share_stream`；网关分享按项目和任务双重过滤，隐藏引擎内部事件，禁止通过 socket 发写指令。
- Web 复用现有实时消息处理和重连恢复；网关分享不再进入定时轮询分支。首次载入及连接恢复补读快照，有变更事件或写操作时刷新；打开预览不随快照刷新重新加载。

验证：Web 相关 15 项通过；daemon 原有分享/主事件流/桥接等 68 项通过，补充拒绝场景与慢验签健康检查后桥接 19 项通过；Gateway 分享和数据连接 32 项通过；TypeScript 与分享构建通过。浏览器组件测试对只读、可编辑分享均断言建立专用 socket 且无周期快照计时器。

运行状态：本机 daemon PID 46889 未启用热重载，尚未重启；新构建保存在 `/tmp/workstep-share-ws-build`，未覆盖正在使用的分享前端。需后台加载新实现后切换前端并进行浏览器 WebSocket 实测，不能把此前的轮询版手测作为本次实时通道的上线验收。

## 新版实时通道的隔离链路及 Chrome 实测

为避免中断正在托管本轮会话的 daemon（进程树确认本轮引擎是 PID 46889 的子进程），本次使用临时数据库、测试身份和模拟任务数据，在仅监听回环地址的隔离测试服务中加载新构建；没有重启日常后台、覆盖日常分享前端或修改真实项目。测试结束后两条隔离分享均已撤销，活动 WebSocket 数为 0，临时服务正常退出并清理其数据库。

验证边界：Gateway 的分享创建、解锁、会话校验、撤销 API、WebSocket 路由、`DataConnection` 转发、daemon 验签桥接和 `_serve_share_stream` 都执行实际代码。隔离浏览器环境的任务/历史/产物 HTTP 数据与保存结果由夹具提供，没有调用真实 LLM。不能将这些结果等同于日常宿主、桌面安装包或远程部署已升级后的验收。

## HTML 分享预览与链接密码提示

在用户提供的现有分享中打开 UI 设计稿，浏览器 iframe 显示“此页面已被 Chrome 屏蔽”。独立访客请求确认该地址是下载接口：`Content-Type: application/octet-stream`、`Content-Disposition: attachment`，且响应包含 `frame-ancestors 'none'`。HTML 正文可以通过受授权的 preview 接口完整读取。

修复不改下载响应或放宽网关 CSP：分享的文件能力声明 `isolatedHtml`，共用预览组件使用读取到的 HTML 生成 srcdoc，sandbox 允许脚本和弹窗但不开放同源权限，设置 no-referrer。页内片段链接在隔离文档内部滚动，避免跳转成嵌套分享页。原下载入口继续保留。

复制和显示分享地址时，公共工具将密码编码到 `_t`，保留原查询和片段；分享页只自动填入密码框，不自动提交密码。桌面/本地/远程分享弹框及网关门户复用该工具；复制文案继续由现有四语言标签生成。

浏览器实测使用用户提供的同一份 HTML 内容（约 10 万字符）与隔离分享：只读和可编辑页面均可不手动输入密码直接点击解锁；HTML 主体实际显示，章节 B 跳转后仍是设计稿；“在新窗口打开”实际显示独立预览而非下载。用户原有分享未撤销、原任务及产物未修改，隔离测试分享和临时服务随后清理。

回归先复现 HTML 错用下载 URL、密码提示未填写和复制地址未带 `_t`，修复后 Web HTML/Markdown/下载/分享/i18n 相关 36 项通过；网关门户分享创建、已有分享复制与撤销 2 项通过；Web TypeScript 与隔离分享构建通过。

部署边界仍然存在：本次新构建仅用于隔离验证，日常网关分享前端尚未切换；需宿主加载 WebSocket 实现后一起更新，不能以本次隔离验证宣称用户现有地址已经更新。
