## 方法与限制

- 只测 WorkStep，未重跑 OpenViking；不能当作同模型全量双系统对照。
- 官方 LoCoMo10 数据；纳入类别 1–4，排除类别 5，共 1540 题。
- 使用 OpenViking Hermes 官方 grade_answer 原始裁判提示词。回答与裁判：朴食 teamplan / gpt-5.6。
- 提炼、回答阶段隔离参考答案；裁判阶段才读取参考答案。未因答错而重新作答。
- 每组隔离数据库；每批 100 条，提炼后复用于本组全部问题；答题并发 4、最多 10 次工具调用。
- 双人对话按真实人类角色导入，保留说话者、时间及图片说明；历史索引显式登记。
- 后半程提前准备后续组，组内进程锁避免重复提炼；模型参数和答题提示词不变。
- 提炼期间第一组发生 JSON 格式失败，第八组发生实体别名 UNIQUE 约束失败；均保存成功批次后断点重试完成。未修改正式程序。
- 本地原始产物位于仓库根目录 `tmp/locomo-comparison/full-workstep/`：每题答案与检索证据为 `groups/*/answers/*.json`，评分理由为 `groups/*/grades/*.json`，统计为 `summary.json`，测试清单为 `manifest.json`。这些临时产物未随本文归档，其他检出环境可能不存在。
- 这是一轮单次抽样运行，没有多随机种子重复测试。
