### 网关断线恢复
宿主网关认证成功及重连时由 daemon `services/gateway_client/service.py::_sync_account_name` 调用 `ConfigStore.sync_gateway_user`，把已验证账号显示名写入本机用户设置；显式关闭连接后保留最后同步的名称并恢复自定义。Web `userSettingsStore.ts` 同步覆盖当前浏览器名称，`browserActor.ts` 对网关模式停止发送本地自报身份头；`BrowserActorMiddleware` 停用宿主旧浏览器身份回退，`DesktopSecurityMiddleware` 在解析认证会话后，对仍缺少网关身份的宿主请求拒绝任务、消息、定时等身份操作，防止旧浏览器身份创建任务，认证与连接设置入口仍可用。局域网访客、项目范围与渠道身份继续沿用各自边界，不继承宿主账号。`record_one_shot_usage` 读取显式调用身份；没有调用身份时使用已认证连接账号，不把本机设备身份当成网关账号。测试入口为 daemon `test_gateway_account_settings.py`、`test_gateway_reconnect.py`、`test_gateway_client.py`、`test_gateway_usage_outbox.py`，Web `userSettings.test.ts` 与 `browserActor.test.ts`。
网关页面的实时连接由 `apps/web/src/hooks/useWebSocket.ts` 管理，会话检测由 `components/GatewayRemoteFrame.tsx` 管理；二者通过 `stores/gatewayRecoveryStore.ts` 共享暂停状态。初次失败后最多自动重试 3 次，耗尽时停止连接和 `GatewayDeviceTabs` 的设备目录轮询，由 `components/GatewayConnectionProblem.tsx` 复用确认弹窗告知用户。关闭弹窗、窗口聚焦、网络恢复不会解除暂停，仅“重新连接”重置预算；WebSocket 须稳定连接 30 秒才自动重置预算，避免开关抖动无限刷新。会话 401/403 沿用重新授权入口，不放宽权限；本机非网关连接保留原重连策略。暂停日志仅记录数值状态码及重试次数，不记录地址、票据或响应正文。
