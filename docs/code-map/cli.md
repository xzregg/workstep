CLI 凭据目录沿用 `services.config.CONFIG_DIR`（显式 `WORKSTEP_CONFIG_DIR` 优先），避免测试隔离配置后仍覆盖真实实例；POSIX 发布时拒绝覆盖另一个存活进程的同地址凭据。缺失凭据导致本机 401 时，客户端提示重启目标 daemon 重新生成，不再误导为浏览器登录。`test_local_cli.py` 同时覆盖经本机认证读取远程任务、本机 Token 不转发，以及远端 403 原样保留。
协调提示词按职责分层：`COORDINATOR_ROLE_RULES` 是注册配置与实际调用共用的角色、授权和阶段控制规则；`assemble_context` 仅补充输出协议、提案字段和来源解释，定时与恢复会话说明按执行模式加入。快捷脚本、工作树和定时 CLI 参数细节由 `apps/daemon/data/skills/workstep-cli/SKILL.md` 按需提供，避免在每轮固定提示词中重复。上述上下文测试同时限制普通回合长度并验证定时规则只在定时回合出现。

目录弹窗上传由 `apps/web/src/components/ProjectDirectoryUpload.tsx` 持有文件选择、多文件上传、状态与错误恢复；`ProjectDirectoryBrowser.tsx` 在显示隐藏文件开关左侧装配，持有所选目录并刷新文件树。`api/client.ts::fsApi.uploadToDirectory` 调用 `api/fs_browser.py::upload_browser_file`，保留原文件名、拒绝覆盖并限制浏览根目录，文件解码与写入在工作线程执行。行为测试见 `apps/web/tests/projectDirectoryUpload.test.tsx`、daemon `tests/test_api_contracts.py`（上传边界及慢写入健康检查 canary）。
Android 语音权限由 `apps/android/app/src/main/java/com/workstep/android/MicrophonePermissions.java` 将 WebView 音频请求接到 Android `RECORD_AUDIO` 运行时授权；Manifest 声明录音权限且麦克风硬件为可选。`MicrophonePermissionGate` 持有单个待处理请求，只允许配置服务同源、安全上下文中的音频采集；系统授权返回时重新核对当前页面和服务，导航、页面销毁、后台或网页取消后不补发授权，并拒绝摄像头和未知资源。`MainActivity` 仅转发 WebChromeClient、运行时授权结果与生命周期。行为测试：Android `MicrophonePermissionGateTest`；旧 APK 需要重新安装更新，普通局域网 HTTP 仍不支持网页录音。
文件与产物预览、目录浏览弹窗的标题路径统一复用 `components/CopyablePath.tsx`，点击复制完整显示路径并反馈成功／失败，复用 `utils/clipboard.ts` 兼容非安全上下文；行为测试：`tests/previewPathCopy.test.tsx`。
iOS 音视频与系统朗读：`apps/ios/WorkStep/BrowserViewController.swift` 管理同源主框架的摄像头／麦克风权限请求与导航／后台失效，`Core/MediaCapturePolicy.swift` 持有采集来源策略和朗读请求校验；`SystemSpeech.swift` 持有系统合成、逐句回执和停止，`Resources/bridge.js` 对齐共享 `WorkStepSpeech` 协议。图片附件沿用 WKWebView 系统选择器；不新增后端 API。回归：`WorkStepTests/ClientPolicyTests.swift`、`tests/bridge.test.mjs`、`tests/project.test.mjs`、Web `speechOutput.test.ts`；iOS 平台采集、扬声器和签名安装仍需实机验证。
移动原生采集授权：Android `MicrophonePermissions` 将 WebView 请求中的音频／视频映射为实际缺失的 `RECORD_AUDIO`／`CAMERA` 权限，`MicrophonePermissionGate` 统一校验同源、请求资源及导航生命周期；带声音视频需全部系统权限通过。iOS `MediaCapturePolicy` 与 `MediaCaptureAuthorization` 校验同源主框架，`BrowserViewController` 对 `.cameraAndMicrophone` 依次申请系统相机与麦克风并在回调间复核上下文。回归：Android `MediaCapturePermissionsTest`、`MicrophonePermissionGateTest`，iOS `ClientPolicyTests.testMediaCaptureAndSpeechRequests`。
