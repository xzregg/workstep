# HTML 原型编辑器

入口：项目 HTML 预览右上角「原型编辑」。分享预览、只读项目不提供编辑入口。
设置 → Agent 助手中的「原型助手」复用现有引擎、供应商、型号与思考配置。

## 使用与布局

弹窗支持标题栏拖动、四边四角缩放、最大化；聊天和属性面板之间的分隔栏可拖动。
左侧复用 AssistantChatPanel / ChatInput。中间预览内的折叠目录始终以当前 HTML 所在目录为根，显示该目录内文件及子目录，隐藏副本中的其他目录（包括旧副本的无关资源）；
复用代码对比的文件树组件，提供搜索、文件计数、图标及全部展开／收起。默认收起，通过预览工具栏「文件目录」或标题文件名展开，点击 HTML 可切换；切换后自动收起，支持调整浮窗尺寸；右侧提供文字、颜色、字号、尺寸、间距等属性。
窄屏改用聊天／预览／属性标签。

点选模式：悬停高亮并显示评论框，点击锁定元素，右键进入该元素的评论；发送评论后进入当前
HTML 的聊天。点击会锁定评论目标，后续悬停不替换它；发送消息会显示文件／行号、元素选择器、节点 ID 及原文，评论重试沿用发送时的定位快照。可选父元素、双击纯文字元素修改、拖动尺寸、确认删除选中的具体节点。
选中后仅按住选框右上方的移动图标拖柄可移动位置，距父容器内容边缘／同级元素边缘不足 3 像素时吸附并显示对齐线，离开范围立即脱开；
Alt 临时关闭吸附，Esc 或取消指针操作恢复原位。松开后通过独立 CSS `translate` 写回并支持撤销，
位置不限制在父元素范围内，跨出后仍按新位置保存，但保留源码父子关系及父容器原有 overflow 裁剪规则。保留已有 `transform`；普通 inline 文字、父级含旋转／缩放等复杂坐标轴的元素暂不开放移动。
拖动期间暂时隐藏评论浮层，避免遮挡。预览工具栏提供撤销按钮，Ctrl+Z／⌘Z 可连续回退已保存操作（含移动、尺寸、文字和样式）；输入框及行内文字编辑保留原生文本撤销，历史弹窗和确认框内不触发文件撤销。保存中或无可撤销记录时禁用，重复快捷键不会并发提交。
包含子元素或注释的容器不能直接替换文字；html/body/head/script/style 不能直接删除。
数值属性提供与文本输入双向同步的横向滑条，拖动沿用当前单位并实时预览，松开鼠标或结束键盘调整后保存一次；多值间距（如 `8px 16px`）保留文本编辑。属性面板输入文字、尺寸、颜色等时即时更新 iframe 内的 DOM 草稿；颜色选择器拖动时同步预览。失焦或在样式输入框按 Enter 后提交版本化源码补丁，非法样式不保存，保存失败恢复预览原值。草稿不直接序列化回写，属性与鼠标编辑均不消耗模型调用。

点选模式只运行带随机 nonce 的编辑桥接脚本，整个框架树的页面脚本暂停，本地静态子框架由可信桥接加载，防止待编辑页面
伪造文件修改消息。浏览模式运行原型脚本，但不接受编辑消息。动态生成的页面结构和框架源码
不承诺可视化回写，应交给助手检查生成逻辑；本版的直接编辑目标是静态 HTML 源节点。

## React 等运行时渲染页面

识别带脚本和空 `root`／`app`／`__next` 挂载点的 HTML 壳后，进入动态检查模式：保留页面脚本渲染，可高亮、点选、取得真实 DOM 选择器和文字并发送评论。原型助手在该 HTML 所在副本目录修改生成脚本，正常发布后刷新。对内嵌压缩包只提供定位和简短搜索提示，不把整包或序列化 DOM 放入提示词。

动态节点不映射为静态源码节点，属性面板只读、拖柄隐藏；宿主拒绝页面脚本发起的自动修改／删除／撤销消息，服务端也拒绝对此 HTML 壳直接打属性／文本补丁。显式发送的评论仍走已有助手会话和发布链路，已有交互脚本不被静态快照替换。此模式当前支持独立打开的动态页面；动态父页面中的子框架不接入自动编辑路由，静态外层中的动态子页可从目录单独打开检查。画布／WebGL 内的图形只能定位到 canvas，不能自动定位到绘制的具体图形。

验证：`test_prototype_api.py`、`prototypeEditor.test.tsx`；`scripts/check-prototype-runtime.mjs [HTML 路径]` 用真实 HTML/CSP 在不透明沙箱中验证渲染、选择器、文字和只读源码映射。已用 `tmp/voice-presence-preview/preview.html` 的 React 打包页面验证标题点选，未改写该原文件。

## 页面跳转与嵌套 iframe

已实现：浏览模式点击工作区内 HTML 链接，目标 HTML 响应由 `html_preview.prepare_editor_html` 注入仅报告路径的导航通知。宿主 `PrototypeEditor` 同时校验顶层预览 WindowProxy、当前票据及已登记文档，切换当前文件、标题、目录范围和该文件聊天；清空旧节点定位并重新取得目标文件的版本和点选票据。之后的修改写回目标文件。点选模式的单击仍用于选择元素，跳转请切换浏览模式。锚点不切文件，外部链接、其他窗口及未登记文件不作为编辑目标。存在未发送评论或保存任务时回到原页面并提示，不丢弃评论。普通文件预览／分享票据不注入该通知。

已实现：外层菜单＋本地静态 iframe 的原位编辑。先在「浏览」模式通过菜单／链接 `target` 切换内容，再进入「点选」，会恢复各框架刚才的本地页面。点击子页面元素后，标题、目录和聊天切到该文件；外层预览入口独立保留。属性、文本、拖动、评论、父元素和撤销命令沿活动框架路由发送。跨文件悬停不抢走已选目标，切换选中框架时清掉另一层的旧选框。存在未发送评论时模式按钮禁用，已登记子框架的跨文件导航会恢复原页面并提示，避免评论跟错文件。

- `data/prototype-frames.js` 对每一层直接子 iframe 的 WindowProxy 验证后转发消息，携带文件、版本及框架路径；`prototypeFrameRouting.ts` 只接受顶层可信预览窗口、当前票据及已登记文件，对不同文件相同节点编号隔离。属性草稿和刷新命令按框架路径分发。
- 子框架选择框在自身文档中绘制，评论矩形逐层换算 iframe 边框、缩放和滚动。滚动后桥接报告最新矩形。提示词只额外增加简短的 `frame_path`（文件＋iframe 选择器），不复制整个外层源码。
- 回写和撤销复用现有文件版本补丁及工作区事务，刷新受影响子文件的实例，保留外层和未修改框架。若撤销改变的是外层入口，则重载外层并恢复子页面路由。共享样式／助手跨文件改动涉及外层时，可通过目录重新打开入口刷新完整预览。
- 编辑票据仍不启用 `allow-same-origin`。HTTP／meta CSP 只允许当前票据资源子树中的子框架；prototype 票据移除不透明祖先不兼容的 `frame-ancestors 'self'`，普通预览／分享的该规则不变。整个框架树仅运行 nonce 桥接；点选预览禁用 HTML meta refresh（不写回源码），防止自动跳转替换可信编辑文档。编辑消息还核对票据与文件版本，切换模式期间未取得编辑预览时拒绝旧浏览脚本消息。
- 支持已收集的本地 HTML、静态 `iframe src`、菜单链接 `target` 及多层嵌套；`srcdoc`、外部跨域页面、依赖运行时生成的 iframe／DOM 不开放直接回写。没有源码映射的内容交给助手修改生成逻辑。当前真实浏览器验收覆盖本地预览链路，Gateway 转发链路未单独验收。

验证：`test_prototype_api.py` 覆盖子文件回写／撤销且外层不变，`test_prototype_assistant.py` 覆盖子文件定位提示，`prototypeEditor.test.tsx` 覆盖会话、编辑路径、局部刷新和模式切换保护，`prototypeFrameRouting.test.ts` 覆盖票据／版本及路由恢复。`scripts/check-prototype-frames.mjs` 使用真实服务端 HTML/CSP、浏览器不透明沙箱验证两层点选、缩放／滚动坐标、局部草稿、仅刷新子框架、原型脚本隔离、菜单 target 跳转及路由恢复；不启动日常 WorkStep 服务。

## 源码与会话

`services/prototype_source.py` 解析原文字符区间，并为每次预览注入临时 `data-ws-node`。
文件 SHA-256、节点 ID、原文片段、行号和父级链共同构成助手定位上下文。后续每轮正文仅带当前文件、非空的静态依赖清单（相对页面 cwd）及必要定位：静态元素带节点 ID、行号、CSS 选择器、最多 200 字符原文和最多 1200 字符源码（超限标明截断），不再发送计算样式、坐标、父级链或版本哈希；动态元素只带非空标签／ID／class 和最多 200 字符文字。无选择、无外部依赖时仅带文件名和原始修改要求，聊天显示用的定位引用不重复塞入 User request。旧聊天记录、旧提示词和引擎续聊状态保持不变，完整源码按需读文件。标记与桥接脚本不会
写回源文件；后台只替换选中的源码区间，样式通过 CSS 声明解析保留其他属性，不序列化 DOM。
版本不匹配返回 409，要求重新选择，不能凭旧节点编号覆盖新内容；助手发送和执行前同样核对定位版本。

每个目录工作区与每个 HTML 都有稳定 UUID；路径作为定位索引，不把路径 MD5 当会话身份。
`prototype_sessions` 在项目数据库持久化聊天，`prototype:<project>:<document>` 为会话 ID，
独立 `prototype` WebSocket channel，多个文档共享目录副本并串行写入。
新同级文件在重新打开工作区时登记；空闲工作区刷新会跳过已删除的历史入口及其目录，不影响新文件打开；外部重命名暂按新文档处理，不自动猜测会话迁移。

后端 `agent_assistants/prototype.py` 通过 AssistantConfig 注册，继承 AssistantRuntime，
复用会话、流式事件、停止、错误、历史与引擎配置。引擎 cwd 是副本中当前 HTML 的目录。
`engine_project_context.py` 保留原项目的身份、技能与数据目录，不把副本登记成新项目。
通用 runtime 只增加可选的 session_cwd_resolver；发布在 runtime 完成事件之前执行，
回写冲突以失败回合持久化；前端观察回合结束立即刷新预览，不等待下一次轮询。提示词要求最小改动、默认只改当前文档，明确要求才跨文件修改。

## 副本、回写与容量

目录由 `Project.workstep_dir` 解析，兼容项目内／外部数据存储：

```text
<项目数据目录>/prototype-editor/<workspace UUID>/
  journal.json         # 原始目录、文档身份、版本、待发布事务
  workspace/           # 引擎与预览使用的持久副本
  history/<sha256>      # 内容寻址快照
```

资源收集由 `services/prototype_resources.py` 负责：以当前文件及同级 HTML 为入口，
沿 HTML 的本地资源／页面链接、CSS 的 `url()`／`@import`、JS 的字面量 import／require／URL／fetch
递归补齐 HTML/CSS/JS、JSON、图片和字体，不再递归复制原始目录内全部白名单文件。
子目录中未被引用的页面可以单独打开；打开后登记为入口，后续刷新保留文档身份。
排除隐藏目录、依赖、构建产物和符号链接，不访问网络，不复制越出原型工作区的引用。
动态拼接出来的资源路径不做静态推断；这类原型需要先使用明确的本地资源引用。
单文件上限 25 MiB，所选资源总量上限 500 MiB；超限提示包含具体资源相对路径。这些是源资源限制，并非模型运行目录的硬磁盘配额。
历史保留最近 30 次修改，按 200 MiB 软预算移除最早历史，再回收无引用快照。
当前基线及未完成事务不因清理被删除，因此必要快照可超出软预算。不同工作区分别计量。
「修改历史」在独立可缩放弹窗中显示占用、带修改时间的记录列表及源码差异；右侧复用 Git 代码对比，带行号和红绿增删标记，可切换并排／统一视图及同一记录中的文件。打开／关闭不改变主窗口尺寸或分栏位置。可清理历史，保留当前文件及聊天；不会自动删原目录。

每轮开始刷新原文件并记录基线。正常结束检测 HTML/CSS/JS 差异，检查原文件仍匹配基线，
先写待发布日志，再逐文件原子替换。多文件回写不是一个文件系统原子事务；中断时日志记录
每个文件的前后哈希，重新打开可继续完成回写，不能静默覆盖期间的新外部修改。
服务重启识别旧进程留下的 running 状态，展示「恢复保存／放弃未完成修改」。停止和错误
保留副本，原文件未发布部分不受影响。修改历史可逐次撤销，撤销前同样检查原文件版本。

本版发布已有 HTML/CSS/JS 文件的修改；模型新增、删除整个文件或修改二进制资源会显示冲突，
保留工作副本供检查。不会把部分受支持文件悄悄发布并丢掉其他修改。
引擎 cwd 和提示词不是操作系统沙箱；底层引擎仍遵循自身已有权限设置。

## 离线练习页面

可使用 [原型编辑练习页](../plans/prototypes/prototype-editor-demo.html) 练习选择元素、修改文案与样式、评论和撤销。它是无真实项目数据的静态样例，不是应用实现或模型验收结果；编辑前可复制到自己的演示项目。
