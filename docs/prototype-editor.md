# HTML 原型编辑器

入口：项目 HTML 预览右上角「原型编辑」。分享预览、只读项目不提供编辑入口。
设置 → Agent 助手中的「原型助手」复用现有引擎、供应商、型号与思考配置。

## 使用与布局

弹窗支持标题栏拖动、四边四角缩放、最大化；聊天和属性面板之间的分隔栏可拖动。
左侧复用 AssistantChatPanel / ChatInput。中间预览内的折叠目录显示同目录及子目录资源，
支持固定展开、调整浮窗尺寸和切换 HTML；右侧提供文字、颜色、字号、尺寸、间距等属性。
窄屏改用聊天／预览／属性标签。

点选模式：悬停高亮并显示评论框，点击锁定元素，右键进入该元素的评论；发送评论后进入当前
HTML 的聊天。可选父元素、双击纯文字元素修改、拖动尺寸、确认删除选中的具体节点。
包含子元素或注释的容器不能直接替换文字；html/body/head/script/style 不能直接删除。
属性与鼠标编辑直接调用版本化源码补丁，不消耗模型调用。

点选模式只运行带随机 nonce 的编辑桥接脚本，页面自己的脚本和子框架暂停，防止待编辑页面
伪造文件修改消息。浏览模式运行原型脚本，但不接受编辑消息。动态生成的页面结构和框架源码
不承诺可视化回写，应交给助手检查生成逻辑；本版的直接编辑目标是静态 HTML 源节点。

## 源码与会话

`services/prototype_source.py` 解析原文字符区间，并为每次预览注入临时 `data-ws-node`。
文件 SHA-256、节点 ID、原文片段、行号和父级链共同构成助手定位上下文。标记与桥接脚本不会
写回源文件；后台只替换选中的源码区间，样式通过 CSS 声明解析保留其他属性，不序列化 DOM。
版本不匹配返回 409，要求重新选择，不能凭旧节点编号覆盖新内容。

每个目录工作区与每个 HTML 都有稳定 UUID；路径作为定位索引，不把路径 MD5 当会话身份。
`prototype_sessions` 在项目数据库持久化聊天，`prototype:<project>:<document>` 为会话 ID，
独立 `prototype` WebSocket channel，多个文档共享目录副本并串行写入。
新同级文件在重新打开工作区时登记；外部重命名暂按新文档处理，不自动猜测会话迁移。

后端 `agent_assistants/prototype.py` 通过 AssistantConfig 注册，继承 AssistantRuntime，
复用会话、流式事件、停止、错误、历史与引擎配置。引擎 cwd 是副本中当前 HTML 的目录。
`engine_project_context.py` 保留原项目的身份、技能与数据目录，不把副本登记成新项目。
通用 runtime 只增加可选的 session_cwd_resolver；发布在 runtime 完成事件之前执行，
回写冲突以失败回合持久化。提示词要求最小改动、默认只改当前文档，明确要求才跨文件修改。

## 副本、回写与容量

目录由 `Project.workstep_dir` 解析，兼容项目内／外部数据存储：

```text
<项目数据目录>/prototype-editor/<workspace UUID>/
  journal.json         # 原始目录、文档身份、版本、待发布事务
  workspace/           # 引擎与预览使用的持久副本
  history/<sha256>      # 内容寻址快照
```

只复制原型 HTML/CSS/JS、JSON、图片和字体白名单，排除隐藏目录、依赖、构建产物和符号链接。
单文件上限 25 MiB，原始资源总量上限 500 MiB；这些是源资源限制，并非模型运行目录的硬磁盘配额。
历史保留最近 30 次修改，按 200 MiB 软预算移除最早历史，再回收无引用快照。
当前基线及未完成事务不因清理被删除，因此必要快照可超出软预算。不同工作区分别计量。
「修改历史」显示占用与源码差异，可清理历史，保留当前文件及聊天；不会自动删原目录。

每轮开始刷新原文件并记录基线。正常结束检测 HTML/CSS/JS 差异，检查原文件仍匹配基线，
先写待发布日志，再逐文件原子替换。多文件回写不是一个文件系统原子事务；中断时日志记录
每个文件的前后哈希，重新打开可继续完成回写，不能静默覆盖期间的新外部修改。
服务重启识别旧进程留下的 running 状态，展示「恢复保存／放弃未完成修改」。停止和错误
保留副本，原文件未发布部分不受影响。修改历史可逐次撤销，撤销前同样检查原文件版本。

本版发布已有 HTML/CSS/JS 文件的修改；模型新增、删除整个文件或修改二进制资源会显示冲突，
保留工作副本供检查。不会把部分受支持文件悄悄发布并丢掉其他修改。
引擎 cwd 和提示词不是操作系统沙箱；底层引擎仍遵循自身已有权限设置。

## 验证入口

- 后端：`test_prototype_source.py`、`test_prototype_workspace.py`、`test_prototype_api.py`、`test_prototype_assistant.py`。
- 前端：`prototypeEditor.test.tsx`，覆盖真实组合组件的精确编辑、目录切换与评论发送。
- 浏览器：`scripts/check-prototype-editor.mjs` 检查真实沙箱内点选、右键、文本、拖动、删除及阻止页面伪造消息。
- 布局：`scripts/check-prototype-layout.mjs` 离线渲染真实组件与构建 CSS，在 390/1023/1280/1600 宽度验证布局。
- 慢文件 I/O、慢 SQL 与实时轻量请求／协程 canary；API 检查项目编辑权限和跨项目拒绝。

测试通过假引擎驱动真实 AssistantRuntime，不调用付费模型。真实引擎端到端编辑和 Electron 原生窗口
仍需运行应用后验收。操作手册按项目约定，在本批合并交付节点集中更新并采集模拟项目真实截图。
