WorkStep 桌面沙箱

Electron 管理运行环境；daemon 管理项目、工作流与引擎执行。以下对应 feat/desktop-sandbox 的当前实现。

01 · 整体架构

不开沙箱时，Electron 使用桌面自带 Python 启动本机 daemon，runtime 位于当前配置目录下，默认是 ~/.workstep/runtime。开启沙箱时，容器 Home 来自用户选定的 沙箱目录/home；同步宿主引擎配置是复制操作。

02 · 开启、运行与清理流程

macOS 使用 AppleHV，Windows 使用 WSL2，Linux 使用宿主 rootless。系统虚拟化前置能力不会随沙箱删除。图中合并了下载辅助程序、连接配置、日志和备份细节。
