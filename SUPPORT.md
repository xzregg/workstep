# Support

- Reproducible defects: Bug report Issue form.
- Actionable product requests: Feature request form.
- Setup help, questions, ideas, and show-and-tell: [GitHub Discussions](https://github.com/xzregg/workstep/discussions).
- Vulnerabilities: follow [SECURITY.md](SECURITY.md) and report privately.

Include the WorkStep version, operating system, installation method, and a minimal sanitized example. Never publish tokens, private project content, or personal filesystem paths.
