# Contributing to WorkStep

Search existing Issues and Discussions before starting. Use Issues for reproducible bugs and actionable requests; use Discussions for setup help, broad ideas, proposals, and questions. Agree on direction before investing in a substantial behavior change.

## Pull requests

1. Keep the change focused and link its Issue when one exists.
2. Add or update tests for behavior changes.
3. Run the relevant checks in [`docs/development.md`](docs/development.md).
4. Update English and Simplified Chinese documentation together for public changes.
5. Include screenshots or a short recording for visible UI changes.
