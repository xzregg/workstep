# 任务看板视图切换 · 原型 A

> 分段控件 + 扁平表格
> 配套可交互 HTML: `prototypes/board-view-toggle-A.html`

## 方案概述

在顶栏右侧新增 `泳道 | 表格` 分段控件(SegmentedControl),一键切换看板显示方式。表格模式为不分组的扁平表,步骤以彩色圆点列呈现,列头点击排序。

## 布局示意

### 切换器(顶栏)

```
┌─────────────────────────────────────────────────────────────┐
│ 任务看板  电商后台重构        [🔍 搜索任务…]    ( 泳道 | 表格 ) │
└─────────────────────────────────────────────────────────────┘
```

### 泳道模式(现状,保留)

```
┌──────────────┐ ┌──────────────┐ ┌──────────────┐
│ ● 需求 (2) + │ │ ● UI设计 (2)+ │ │ ● 前端 (3) + │  ← 横向滚动
│ ┌──────────┐ │ │ ┌──────────┐ │ │ ┌──────────┐ │
│ │ 任务卡片  │ │ │ │ 任务卡片  │ │ │ │ 任务卡片  │ │
│ └──────────┘ │ │ └──────────┘ │ │ └──────────┘ │
└──────────────┘ └──────────────┘ └──────────────┘
```

- 行悬停高亮,点击行跳转任务详情(与卡片点击行为一致)

## 交互规则

1. 切换即时生效,无过渡动画(首版)
2. 选择持久化到 `localStorage`,下次进入沿用上次视图
3. 移动端默认列表(现状),不展示切换器
4. 归档视图同样支持两种显示

## 实现要点

- 落点在 `apps/web/src/pages/TaskList.tsx`:
  - 顶栏区(约 920 行附近)追加分段控件
  - 新增 `viewMode` state + 一个 `<TaskTableView tasks={visibleTasks} lanes={lanes} />` 分支
  - 表格行复用现有 `STATUS_LABEL_KEYS` / `STATUS_COLORS` 与卡片元信息
- 预计改动量:小(约 150~250 行)

## 优缺点

- ✓ 实现简单:复用现有卡片数据,只加一个视图分支
- ✓ 信息密度高,适合批量扫读和排序
- ✗ 扁平化弱化了「步骤归属」的视觉分组,看板感消失
- ✗ 步骤多时,圆点列难以一眼看清各步骤的任务分布
